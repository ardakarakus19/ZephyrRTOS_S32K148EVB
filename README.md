# ZephyrRTOS_S32K148EVB
Welcome to the Zephyr RTOS project repository for the NXP S32K148 microcontroller. This repository serves as a practical guide and codebase for running Zephyr RTOS on the S32K148-EVB platform. It includes custom device tree overlays, peripheral driver configurations (such as CAN, ADC, eDMA, and GPIO), and real-time multi-threading implementations.
